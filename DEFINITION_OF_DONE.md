# DEFINITION OF DONE

***A phase is considered COMPLETE only when:***

✓ Project compiles
✓ Docker starts successfully
✓ Frontend starts
✓ Backend starts
✓ Database migration successful
✓ Redis connected
✓ APIs tested
✓ WebSocket connected
✓ No runtime errors
✓ No TypeScript errors
✓ No ESLint errors
✓ README updated
✓ Tests pass

**Only then continue to the next phase.**
